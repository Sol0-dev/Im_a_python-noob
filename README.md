To complete the **Moore's Law** challenge, update line 5 to apply the exponential growth formula and then print the result on line 6.

### **How it works:**

* **`2 ** (years / 2)`**: The `**` operator calculates exponents in Python. Since transistors double every 2 years, we divide `years` by `2` to get the number of doubling periods ($10 / 2 = 5$). $2^5 = 32$.
